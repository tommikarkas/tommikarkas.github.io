Solid signage pictograms, 26 of them, inked in `cyan-500` (#3ce0ff) with the colour baked into each file because `<img>` cannot inherit it. Source: the CC0 collection at github.com/apancik/public-domain-icons (Public Icons, AIGA/DOT Symbol Signs, NPS map symbols), each normalised to a square viewBox with 6% padding. Use at 16px beside text, 20px in the comments heading, 14px in the footer, 12px on a badge; on a cyan or amber fill apply `filter: brightness(0)`. The set has no brand logos on purpose: GitHub, Mastodon and RSS marks are trademarked, so write the word and use `external-link`, `mail` or `bolt` beside it. To recolour, edit the `fill` attribute on the `<svg>` root.
