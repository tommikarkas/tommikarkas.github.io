The blog's logo is the rat: a solid side-profile silhouette in `cyan-500` with a `magenta-500` eye, drawn on a 32px grid in the same flat signage style as the icon set. It is original to this system and released CC0 (public domain). `nt-rat.svg` goes in the `SiteHeader` at 24px and anywhere the blog is represented at 48px or more; `nt-rat-mono.svg` is the single-ink version (the eye becomes a `bg-000` cut-out) for places where magenta would clash or only one colour prints; `nt-rat-favicon.svg` is the rat on `bg-000` for the browser tab and home-screen icon. Clear space: one `space-2` on each side; minimum size 16px, below which the eye closes up. The prompt chevron (`nt-mark.svg`, `nt-mark-mono.svg`, `nt-favicon.svg`) stays as a secondary mark for the `> _` rule and for places where an animal would be odd, such as a 404 page's terminal prompt. Do not rotate, outline, add a glow to, or face the rat to the right; it always walks toward the text.
